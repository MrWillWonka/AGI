# The Path to AGI

An incremental game: grow a narrow AI into general intelligence, then superintelligence, then the Singularity.

- In the **Lab** (a workbench, a hardware bench and a software terminal, with more stations to unseal), generate compute, collect data and research to build **Intelligence**, **Creativity** and **Awareness**. Automation converts compute into data and research within a budget you set, so compute always keeps growing.
- Zoom out to the **Facility** to see every room. It grows as you progress, with sealed wings hinting at what's still to come. The **Server room** is a rack of hands-on modules (click a section to zoom in), and **R&D** is where you Transcend.
- **Training Path:** hold to charge each training sprint (stronger sprints cost more compute and data, and releasing in the meter's sweet spot earns extra XP), and drive your model as far as it will go over long stretches of random rolling hills. Near the top of a big hill, time slows down: will it learn the skill or not? After each run you can run again to bank more Experience, or open the Training dev screen and spend it in a skill tree with four branches: Power, Precision, Recursion and Capability. The tree starts with a handful of cheap nodes and grows outward as you unlock it. At the end of each stretch a big skill hill (Pattern Matching, Language Modeling, Theory of Mind…) is the wall to break through.
- Hardware, Software, Algorithms and Consciousness upgrades unlock as you progress.
- Each phase needs minimums in all three attributes.
- **Transcend** to reset a run for permanent Prestige Points (+10% production each).
- 14 achievements (+2% production each), offline progress (up to 8h), autosave, and save export/import.

## Play

No build step. Serve the folder and open it:

```bash
python3 server.py      # opens http://localhost:8000
```

Any static host works (GitHub Pages, Netlify, etc.).

## Develop

```bash
node --test            # engine tests
```

Add `?debug` to the URL, or press the backtick key, for developer tools. See `CLAUDE.md` for architecture notes.
