# Steam / desktop-wrapper readiness (build 58728e8)

- **Network:** the only runtime network dependency is still Google Fonts (`index.html` lines 10-12: Chakra Petch, Atkinson Hyperlegible, JetBrains Mono). No script fetches anything (no fetch / XHR / WebSocket / sendBeacon). Offline, the page falls back to system fonts and the layout (tuned to those metrics) shifts. Bundle the three families (SIL OFL) as local `@font-face` files.
- **Storage:** every read/write goes through `storageGet`/`storageSet` on `localStorage` (save 1.2-5 KB JSON, `agiGame.bak`, `agiGame.corrupt`, about a dozen per-device keys, the playtest log up to 15,000 events). Electron / NW.js / Tauri keep `localStorage` per profile, so it works as is. Steam Cloud wants files: put a one-key-one-file adapter behind `storageGet`/`storageSet`. Saves are versioned and migrate from v1 (real v8-v15 saves from the git history load: see old-saves-results.json), so cloud conflicts reduce to "newest `lastSaved` wins"; the import dialog already shows both summaries.
- **Tab lock:** `claimTab` (BroadcastChannel) is harmless in a single window and gives up quietly where refused.
- **No offline progress:** the gate is `document.hidden` plus a 5 s gap rule in `tick()`, not timers. A minimised Electron window reports hidden (nothing earned, by design); a wrapper with `backgroundThrottling: false` still earns nothing while hidden. A wrapper that never reports hidden (some kiosk modes) would earn while minimised: test the wrapper's visibility events.
- **Window sizing:** full-width layout with CSS `zoom` tiers at 2200/3000/3600 px and phone/tablet tiers below 640/960 px. Set a minimum window of about 1024 × 640.
- **Input:** mouse, touch and keyboard (Space/Enter sprint, U, R, Esc, backtick for debug). No gamepad: a Steam Deck build needs Steam Input's keyboard/mouse mapping or a small Gamepad API layer for sprint/thrust, Esc and the tree camera. Remove or gate the debug panel (backtick, `#debug`, the terminal icon beside Journal) in a release build.
- **Audio:** synthesised Web Audio, no files; unlocks on the first gesture (Electron can skip it with `autoplayPolicy: 'no-user-gesture-required'`).
- **Artifact-only code:** `window.claude?.hot` hand-over and the screen wake lock are no-ops outside the artifact.
- **Content scope:** chapter one ends at Superintelligence (one shipped version, 70-90 min in the balanced sim). The sealed bays and wings are placeholders; a store build needs either the planned content or a clear "chapter one" framing.
